# 00. はじめに

## この教材について

AWS の入門書は世の中にたくさんありますが、多くは「EC2 を立てて Web サーバーを動かして終わり」です。
この教材は逆に、**1 つの実用的なシステムを丸ごと作る**ことを通して AWS を学びます。

題材は「友達と遊ぶ Minecraft 統合版(Bedrock)サーバー」。ただし単に立てるのではなく、
実運用に耐える形で作ります。

- **オンデマンド起動**: Discord の `/mc start` で起動。遊ばないときは停止していて、EBS 代しかかからない
- **自動停止**: プレイヤーが 0 人のまま 15 分経つと、ワールドを保存・バックアップして自動停止
- **障害検知**: 「自動停止が壊れて動きっぱなし」まで想定した 3 層の見張り + 予算アラート
- **すべてコードで管理**: `terraform apply` で Terraform 管理のインフラを構築。
  S3 や管理外の SSM パラメータを含む完全な片付けは 08 章で扱う

「遊ぶときだけ起動して従量課金を最小化する」「壊れる前提で多層防御する」「インフラをコードにする」——
これらはそのまま業務のクラウド設計で使う考え方です。

## 対象読者

- AWS をこれから触る人、または触ったことはあるが「サービス同士のつなぎ方」がピンと来ていない人
- ターミナルの基本操作(`cd`、`ls`、コマンド実行)ができる人
- プログラミング経験は必須ではありません(Python のコードが読めると Bot の中身まで楽しめます)

## かかる費用

**遊ばなければ月 $2 程度、月 40 時間遊んで約 $4.2**(東京リージョン)。

| 項目 | 概算 |
| --- | --- |
| t3a.medium オンデマンド 40h | 約 $2.0 |
| 稼働中の Public IPv4 アドレス 40h | 約 $0.2 |
| EBS gp3 20GB(停止中も課金) | 約 $1.9 |
| CloudWatch アラーム 1 本 | $0.10 |
| Lambda / SSM / S3 / DNS | この規模ではほぼ $0 |
| **合計** | **約 $4.2 / 月** |

ドメイン代とデータ転送量は含みません。料金は変わるため、構築前に東京リージョンの
最新価格を確認してください。24 時間稼働では、インスタンス・Public IPv4・EBS・
アラームを合わせて約 $42/月です。

AWS は使った分だけ課金されるので、「消し忘れ」が一番怖い事故です。この構成には
自動停止・強制停止・予算アラートの 3 つの安全装置が最初から入っています(詳細は [07 章](07-monitoring.md))。
それでも心配な人は、01 章でアカウント全体の請求アラートも設定します。

## 全体像

```
Discord (/mc start)
      │ Interactions Endpoint (HTTP)
      ▼
Lambda Function URL (minecraft-bot)
      │ 署名検証 → ACK → 自分を非同期 invoke
      │ ec2:StartInstances
      ▼
   EC2 (t3a.medium)
      │ ① mc-dns: 自分の Public IP を Cloudflare の A レコードに書き戻す
      │ ② bedrock: Minecraft サーバー本体(起動時に公式 API から最新版を取得)
      │ ③ mc-watchdog: プレイヤー数を監視
      │    - 起動完了 → Discord に「🟢 起動しました」
      │    - 0 人が 15 分継続 → S3 バックアップ → 自分で自分を停止
      ▼
   mc.example.com:19132  ← クライアントはいつも同じアドレスで接続できる
```

ポイントは 2 つあります。

1. **固定 IP(Elastic IP)を使わない。** EIP はインスタンス停止中に課金されるため、
   起動のたびに変わる動的 IP を EC2 自身が DNS に書き戻すことで、固定アドレスを実現します。
2. **Bot は常駐しない。** Discord Bot というと 24 時間動くプロセスを想像しますが、
   Interactions Endpoint 方式なら「コマンドが打たれたときだけ Lambda が動く」ので月 $0 です。

## 事前に用意するもの

| もの | 備考 |
| --- | --- |
| AWS アカウント | [01 章](01-aws-account.md) で作ります |
| 独自ドメイン | Cloudflare で DNS 管理していること(ドメイン代のみ。Cloudflare は無料プラン可)。Route 53 でも OK(教材コードは Cloudflare 前提。理由と移植方法は [03 章](03-ec2.md) 参照) |
| Discord アカウントとサーバー | Bot を置くサーバー。自分で新規作成すれば OK |
| 作業マシン | macOS / Linux / WSL。Terraform >= 1.13、AWS CLI v2、Python 3(pip を含む)、zip |

> **ドメインを持っていない場合**: Cloudflare Registrar 等で `.dev` や `.com` を年 $10 前後で
> 取得できます。IP 直打ちでも遊べますが、起動のたびに IP が変わる構成なので DNS はほぼ必須です。
